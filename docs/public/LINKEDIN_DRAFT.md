# LinkedIn — مسودة للمراجعة والنشر من طرف صاحب المشروع

وصلت لواحد المرحلة مهمة فالمشروع اللي كنخدم عليه: **PerminIA — أول MVP تقني لمنصة تعلم وتتبع موجهة لمدارس السياقة فالمغرب.**

الفكرة بدات من سؤال: كيفاش نعاونو التلميذ يفهم، عوض يبقى غير كيعاود السلاسل ويحفظ الأجوبة؟

فالنسخة الحالية بنيت تجربة مترابطة بين 3 أدوار:

• التلميذ: دروس تدريجية، تدريب بوقت محسوب من الخادم، حفظ واستئناف ومراجعة الأجوبة.
• الأستاذ: متابعة القراءة والمهام وإسناد تدخلات للتلاميذ ديالو.
• مدير المدرسة: الحسابات، الدعوات وربط التلميذ بالأستاذ.

تقنياً استعملت React وFastAPI وPostgreSQL وDocker، مع عزل بيانات المدارس واختبارات للصلاحيات وحفظ المحاولات. بنيت كذلك أساساً لتتبع الإتقان والتدريب الموجّه، وربط مساعد بالدارجة بذاكرة محادثة ومراجع وحدود استعمال عبر OpenAI/Groq.

باش يكون المشروع قابل للتجربة، وجدت ديمو محلي مستقل بداتا اصطناعية. المساعد التوليدي مطفّي فهاد الديمو، وما كيحتاج حتى API key. بنك أسئلة البيرمي المستورد ما داخلش فالنسخة العمومية، حيث اعتماد المحتوى والحقوق باقي مرحلة مهمة قبل تجربة مدارس حقيقية.

هادشي MVP تقني قابل للعرض، والمرحلة الجاية هي مراجعة المحتوى وتجربة ميدانية مع مدرسة سياقة، باش نقيسو الفائدة الفعلية ونبسطو التجربة أكثر.

غادي نفرح بملاحظاتكم، خصوصاً من أساتذة السياقة والناس اللي خدامين فـEdTech وSaaS.
